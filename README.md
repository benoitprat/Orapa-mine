# Orapa Mine – Maître du jeu

Application web pour un seul téléphone posé au centre de la table : elle cache les gemmes, répond aux rayons et aux cases sondées (à voix haute), fait tourner les tours et vérifie les propositions de 1 à 8 prospecteurs.

Jouer : ouvrir la page GitHub Pages du dépôt, puis « Ajouter à l'écran d'accueil ». Une fois ouverte, elle fonctionne hors ligne.

Fichiers : `index.html` (toute l'app, moteur inclus), `manifest.webmanifest`, `sw.js` (cache hors ligne), icônes.

Orapa Mine est un jeu de Junghee Choi et Wanjin Gill (Playte, Gigamic en France). Projet amateur non officiel.
